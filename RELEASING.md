# Выпуск ArsWidget

Публичные сборки: https://github.com/arsenchios/arswidget/releases/latest

## Сборка и упаковка

GitHub Actions → «Выпуск обновления ArsWidget» → Run workflow.
Указать версию и описание. Workflow собирает Release для `arm64 x86_64`,
подписывает приложение и вложенные компоненты через `Configuration/release-sign.sh`,
проверяет подписи, создаёт DMG, ZIP с инструкцией и SHA256SUMS.txt, публикует Release.
Требование: macOS 15+ (минимум встроенного MediaRemoteAdapter).
`LSMinimumSystemVersion` в Info.plist фиксирует этот минимум для LaunchServices. При локальной сборке используйте те же архитектуры,
`ONLY_ACTIVE_ARCH=NO CODE_SIGNING_ALLOWED=NO`, затем скрипт подписи.

Установщик не содержит пользовательских настроек, истории буфера, задач,
разрешений macOS или подключённых аккаунтов автора. Не добавляйте их в пакет.

## Подпись и обновления

Текущая подпись — ad hoc, без Team ID и hardened runtime: иначе встроенный
MediaRemoteAdapter отклоняется системой. Это не Developer ID и не нотарификация.
Первый запуск может потребовать «Открыть всё равно» в настройках безопасности.
Не отключать Gatekeeper глобально.

Обновления устанавливаются вручную из GitHub Releases. Sparkle автоматически
не запускается. Для автоматических обновлений потребуется отдельная настройка
и проверка подписанного канала; создание appcast само по себе её не заменяет.

## Проверки перед публикацией

- Собрать обе архитектуры, проверить `lipo -archs` основного файла и clipboard reader.
- `codesign --verify --deep --strict ArsWidget.app`.
- Проверить менеджер бодрствования, журнал Pomodoro, карточки словаря, историю буфера.
- Проверить размеры и читаемость реальных SwiftUI экранов в изолированных превью.
- Проверить DMG, повторно смонтировать read-only и проверить приложение внутри.
- Вычислить SHA-256 итоговых DMG/ZIP; сверить после скачивания из опубликованного Release.
- Не выдавать локальные проверки за физическое тестирование на другом Mac/iPhone.
