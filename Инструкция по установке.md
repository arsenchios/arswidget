# ArsWidget: установка за 5 минут

## 1. Установка

1. Распакуйте ZIP-архив.
2. Откройте папку `ArsWidget-<версия>`.
3. Перенесите `ArsWidget.app` в папку `Applications`.
4. Откройте приложение.

Если macOS покажет предупреждение о неизвестном разработчике, это ожидаемо для
первой версии без Apple Developer. Нажмите правой кнопкой по `ArsWidget.app`,
выберите «Открыть» и подтвердите запуск. Это нужно сделать только один раз.

## 2. Первый запуск

Появится приветственное окно. Оно коротко покажет основные функции виджета и
предложит включить только нужные разрешения. Базовый виджет запускается и без
них: разрешения нужны для конкретных возможностей.

## 3. Разрешения и конфиденциальность

macOS спрашивает разрешение отдельно для каждой категории. Разрешайте только
то, чем планируете пользоваться. Изменить решение можно в `Системные
настройки` -> `Конфиденциальность и безопасность`.

- **Календарь и Напоминания.** Нужны, чтобы показывать события, списки и
  создавать напоминания. Данные используются внутри приложения для этих
  функций.
- **Универсальный доступ.** Нужен для отображения собственных индикаторов
  громкости и яркости, а также некоторых системных действий. ArsWidget не
  записывает нажатия клавиш и не отправляет их в интернет.
- **Камера.** Необязательна. Нужна только для функции зеркала; видео не
  записывается и не сохраняется.
- **Музыка и Spotify.** macOS может спросить разрешение на управление
  приложением, если включить музыкальные кнопки. Это позволяет только
  запускать, ставить на паузу и переключать треки.
- **Файлы.** Доступ появляется только после того, как вы сами выбрали или
  перетащили файл в соответствующую функцию.

Не хотите использовать функцию - не давайте ей разрешение. Виджет продолжит
работать с остальными вкладками.

## 4. Лимиты Claude и Codex

Это необязательная функция. Для неё устанавливается отдельное Chrome-
расширение. Оно передаёт в ArsWidget только проценты оставшихся лимитов и время
обновления через локальное соединение на этом Mac. Пароли, cookies, переписки и
содержимое страниц не передаются.

## 5. Помощь

Если приложение не открывается или функция не работает, сначала полностью
закройте ArsWidget и откройте его снова. Затем проверьте соответствующее
разрешение в `Системные настройки` -> `Конфиденциальность и безопасность`.
