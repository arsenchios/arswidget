# Украинские ударения

2026-10-08: все 189 карточек разговорного курса и их украинские примеры
содержат ударения U+0301 после гласной. Дополнительный встроенный украинский
словарь также размечен. Односложные слова с гласной размечены для единообразия;
слова без гласной («з», «й», «в») отдельного знака не имеют.

Основной источник проверки словоформ:
[lang-uk: Ukrainian word stress dictionary](https://github.com/lang-uk/ukrainian-word-stress-dictionary),
составленный на основе «Словників України» УМІФ НАН України.
[Описание источника](https://lang.org.ua/uk/produkty/slovniki/dictionary-of-word-stresses-in-the-ukrainian-language/).
Словарь использован при подготовке; приложение не скачивает его при работе.

Омонимичные формы сверены с контекстом: например, «адре́су» для адреса,
«схо́ди» для лестницы, «по́верх» для этажа, «опла́ти» для оплаты.
При допустимых вариантах выбран один вариант, чтобы карточка давала один
понятный образец произношения. «Парко́вка» дополнительно сверена в
[Горох](https://goroh.pp.ua/Тлумачення/парковка).

Добавление ударений не меняет идентификатор карточки (русское поле),
срок повторения, число ответов или исключение «Уже знаю».
Пользовательские переводы сохраняются. Проверки в `tests/VocabLearningTests.swift`
покрывают все карточки и примеры, положение знака на гласной, поиск ответа
в предложении с ударениями и сохранность прогресса.
