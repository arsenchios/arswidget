# Автоматическая история текста — локальная 0.2.29

История хранит до 30 текстов в оперативной памяти. Предел — 64 KiB на запись,
512 KiB на весь текст истории; перезапуск приложения очищает её.

## Чтение и системный буфер

Отдельный `ArsWidgetClipboardReader` опрашивает changeCount раз в 750 мс.
Он проверяет объявленные типы до получения текста и читает только plain text.
Фотографии, видео, аудио, PDF, ссылки на локальные файлы и помеченные
конфиденциальные/временные данные пропускаются без запроса их payload.
Для фото нет декодирования, OCR, преобразования в текст или дискового кеша.
Тексты с меткой Universal Clipboard допускаются: удалённое копирование
само по себе не является основанием исключать текст из истории.

Помощник никогда не вызывает clearContents, setString, setData или writeObjects.
JSON идёт по анонимному pipe в основной процесс, без сети и файлов с содержимым.
Системный буфер меняется только при явном нажатии на текст истории.
Очистка истории не очищает системный буфер.

Чтение NSPasteboard может инициировать системную передачу с iPhone; отдельный
процесс изолирует зависание от интерфейса, но не создаёт независимый канал
Handoff. За 8 секунд без ответа родитель завершает только своего помощника
и выдерживает паузу 30 секунд. Начатое поколение не запрашивается повторно.
Системные pboard/sharingd/useractivityd не перезапускаются и не перенастраиваются.

Сон системы/экрана, блокировка и смена активной пользовательской сессии
приостанавливают чтение. Все причины паузы учитываются независимо. Возврат —
через 3 секунды после снятия всех причин, с сохранённым changeCount.
Выключение истории завершает помощника; при включении изменения за время
выключения не импортируются. EOF stdin завершает помощника при смерти родителя.

## Сборка и проверка

Build phase `Build clipboard reader` собирает Foundation/AppKit CLI из
ClipboardTextReader.swift и tools/clipboard-reader/main.swift для ARCHS.
Помощник подписывается с app-sandbox + inherit; дополнительных разрешений нет.

Изолированный тест tests/ClipboardManagerTests.swift проверяет уникальный
NSPasteboard: локальный и marked-remote promised text, повторную вставку
исходного текста, неизменный changeCount, нулевые запросы фото/файлов/секретов,
замену копирования во время чтения, лимиты/дубликаты, subprocess IPC,
выключение, пробуждение и watchdog. Пользовательский general pasteboard тест
не читает. Имитируемая передача не доказывает реальную связь iPhone↔Mac.
