ARS WIDGET: УСТАНОВКА ЗА 5 МИНУТ

1. РАСПАКУЙТЕ АРХИВ

Откройте ZIP-архив, затем папку ArsWidget-<версия>.
Перенесите ArsWidget.app в папку Applications и откройте приложение.

Если вы скачали ArsWidget.dmg, просто откройте его и перетащите ArsWidget.app
на ярлык Applications в появившемся окне.

Если macOS покажет предупреждение о неизвестном разработчике, это ожидаемо для
первой версии без Apple Developer. Нажмите правой кнопкой по ArsWidget.app,
выберите «Открыть» и подтвердите запуск. Это нужно сделать только один раз.

2. ПЕРВЫЙ ЗАПУСК

Появится короткое приветственное окно. Оно покажет основные функции виджета и
предложит включить только нужные разрешения. Базовый виджет запускается и без
них: разрешения нужны для конкретных возможностей.

3. РАЗРЕШЕНИЯ И КОНФИДЕНЦИАЛЬНОСТЬ

macOS спрашивает разрешение отдельно для каждой категории. Разрешайте только
то, чем планируете пользоваться. Изменить решение можно в:
Системные настройки -> Конфиденциальность и безопасность.

Календарь и Напоминания
Нужны, чтобы показывать события, списки и создавать напоминания. Данные
используются внутри приложения только для этих функций.

Универсальный доступ
Нужен для собственных индикаторов громкости и яркости, а также некоторых
системных действий. ArsWidget не записывает нажатия клавиш и не отправляет их
в интернет.

Камера
Необязательна. Нужна только для функции зеркала; видео не записывается и не
сохраняется.

Музыка и Spotify
macOS может спросить разрешение на управление приложением, если включить
музыкальные кнопки. Это позволяет запускать, ставить на паузу и переключать
треки.

Файлы
Доступ появляется только после того, как вы сами выбрали или перетащили файл
в соответствующую функцию.

Не хотите использовать функцию - не давайте ей разрешение. Виджет продолжит
работать с остальными вкладками.

4. ЛИМИТЫ CLAUDE И CODEX

Это необязательная функция. Для неё устанавливается отдельное Chrome-
расширение. Оно передаёт в ArsWidget только проценты оставшихся лимитов и время
обновления через локальное соединение на этом Mac. Пароли, cookies, переписки и
содержимое страниц не передаются.

5. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

Полностью закройте ArsWidget и откройте его снова. Затем проверьте нужное
разрешение в Системные настройки -> Конфиденциальность и безопасность.
