ARSWIDGET 0.2.31 — УСТАНОВКА И ПЕРВЫЙ ЗАПУСК

Требования: macOS 15 или новее, Apple Silicon или Intel.
Xcode, Codex и команды терминала для обычной установки не нужны.
Официальные файлы: https://github.com/arsenchios/arswidget/releases/latest

1. Скачайте ArsWidget-0.2.31.dmg из официального выпуска.
2. Откройте DMG и перетащите ArsWidget.app на Applications.
3. Запустите ArsWidget из папки «Программы» (Applications), не из DMG.
4. Наведите указатель на островок вверху экрана, чтобы раскрыть виджет.

Обновление: сначала закройте старый ArsWidget через его меню, затем замените
приложение в Applications. Не запускайте одновременно старую и новую копии.
Пользовательские задачи, словарь и настройки при замене приложения сохраняются.

ПЕРВЫЙ ЗАПУСК И ПРЕДУПРЕЖДЕНИЕ macOS

Этот выпуск имеет локальную ad hoc подпись, без Apple Developer ID и нотарификации.
macOS может заблокировать его первый запуск. Если вы доверяете источнику:
откройте Системные настройки → Конфиденциальность и безопасность,
найдите сообщение об ArsWidget и нажмите «Открыть всё равно».
Не отключайте защиту macOS целиком. На управляемом рабочем Mac установка может
быть запрещена политикой администратора.

При необходимости целостность скачанного DMG проверяется по SHA256SUMS.txt,
опубликованному в том же GitHub Release. Контрольная сумма не заменяет доверие
к автору и не является нотарификацией Apple.

ЗНАКОМСТВО И НАСТРОЙКИ

При первом запуске доступны приветствие и тур с иллюстрациями. В нём есть
пауза, переходы вперёд и назад. Повтор: Настройки → Общие → Знакомство → Показать.

Музыка: Apple Music, Spotify и другие поддерживаемые плееры. Отдельная громкость
Apple Music управляет приложением и выбранным в нём AirPlay-выходом.
Pomodoro: выберите время и запустите; задачи и статистика — в «Задачи и итоги».
Словарь: Настройки → Словарь. Готовые наборы — украинский, английский,
индонезийский. Каждый можно включить/выключить; для другого языка есть свой набор.
Буфер: последние 30 текстов только в памяти, очищаются при выходе. Фото и файлы
не сохраняются в текстовую историю. Кнопка записи повторно копирует её текст.
Полка: добавленные перетаскиванием файлы. AirDrop — способ отправки через
«Поделиться», а не автоматическое хранилище полученных файлов.
Система: процессор, память, сеть, временное бодрствование и очистка клавиатуры.
Таймеры бодрствования не меняют постоянные настройки macOS и заканчиваются
автоматически или при выходе. Ручной сон и закрытие крышки не блокируются.
Очистку клавиатуры можно закончить раньше: Control + Option + Command + K.

РАЗРЕШЕНИЯ И ПРИВАТНОСТЬ

macOS может запросить доступ к календарю, напоминаниям, уведомлениям,
управлению музыкальным приложением, камере или выбранным файлам.
Мониторинг ввода нужен для очистки клавиатуры; Универсальный доступ — для
замены системных индикаторов. Разрешайте доступ для нужных вам функций.
Без разрешения соответствующая функция недоступна. Разрешения меняются в
Системные настройки → Конфиденциальность и безопасность.

Анонимная статистика выключена по умолчанию в новой установке.
Параметр: Настройки → Дополнительно → Анонимная статистика использования.
Лимиты AI подключаются отдельно и по желанию; ваши аккаунты не входят в установщик.
В GitHub Release есть ArsWidget-AI-Limits-0.3.8.zip. Распакуйте его в постоянную
папку, откройте chrome://extensions, включите режим разработчика и выберите
«Загрузить распакованное расширение». Затем в popup включите показ лимитов
и откройте страницы Usage собственных сервисов. Не удаляйте папку расширения.
Подробная инструкция открывается из блока подключения лимитов виджета.

ЕСЛИ ВИДЖЕТ НЕ ПОЯВИЛСЯ

Закройте все копии ArsWidget и запустите одну из Applications.
При проблемах с разрешениями проверьте настройки конфиденциальности macOS.
Обновления пока ручные: ссылка на последний выпуск есть в меню и «О приложении».
