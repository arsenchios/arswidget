# Роадмап ArsWidget

## Готово в коде, ждёт финальной проверки

- Музыка, календарь и напоминания
- Pomodoro: задачи, журнал, комментарии и статистика
- Словарь: украинский, английский, индонезийский и свой набор
- Буфер обмена, системный мониторинг и очистка клавиатуры
- Встроенные игры и сохранение их состояния при коротком уходе
- Первый запуск и русско-английский интерфейс
- Подготовка защищённых обновлений через GitHub Releases

## Следующие шаги

1. Собрать и проверить текущую версию в Xcode.
2. Подключить расширение Chrome для лимитов Claude и Codex.
3. Включить GitHub Pages, добавить секрет подписи и выпустить `0.1.0`.
4. Заменить иконку приложения на финальную.
5. Подготовить страницу релиза и получить первые отзывы друзей.

## Идеи на потом

- Статистика и подсказки по лимитам AI
- Проверка состояния Telegram-ботов
- Focus / «Не беспокоить» во время Pomodoro
- Быстрые заметки
- Более глубокая статистика продуктивности
