# Публикация ArsWidget AI Limits в Chrome Web Store

Готовые тексты для формы в кабинете разработчика. Магазин отклоняет или держит
на проверке расширения, у которых не заполнены обоснования разрешений и раздел
о данных — чаще всего дело именно в этом, а не в коде.

## Что загружать

ZIP папки `arswidget-ai-limits`, в котором `manifest.json` лежит **в корне
архива**, а не внутри вложенной папки. Собрать можно так:

```bash
cd chrome-extension/arswidget-ai-limits
zip -r ../arswidget-ai-limits.zip . -x '*.DS_Store'
```

Папка `chrome-extension/tests` в архив не попадает — она лежит уровнем выше
специально для этого.

## Основные поля

**Название**: `ArsWidget AI Limits`

**Краткое описание** (до 132 символов):
```
Остаток лимитов Claude, ChatGPT, Codex, DeepSeek, Gemini, Perplexity, Cursor и Grok прямо в приложении ArsWidget.
```

**Подробное описание**:
```
Расширение для тех, кто пользуется несколькими AI-сервисами и не хочет каждый раз открывать страницу лимитов, чтобы понять, сколько осталось.

После того как вы явно включите показ лимитов кнопкой в окне расширения, оно читает с уже открытых страниц Usage только видимые проценты остатка и передаёт их приложению ArsWidget на этом же компьютере. Проценты видно прямо в виджете, не переключая вкладки.

Поддерживаются:
• Claude — claude.ai/settings/usage (лимит на 5 часов и недельный)
• ChatGPT и Codex — настройки аккаунта на chatgpt.com
• DeepSeek — platform.deepseek.com/usage
• Gemini — aistudio.google.com
• Perplexity — настройки аккаунта
• Cursor — cursor.com/dashboard
• Grok — grok.com

Что расширение НЕ делает:
• не читает и не передаёт пароли, cookies, содержимое чатов и запросов
• не собирает историю посещений и имя аккаунта
• ничего не отправляет в интернет и на сторонние серверы

Данные идут только на локальный адрес 127.0.0.1 на вашем же компьютере, где их принимает приложение ArsWidget. Без запущенного приложения расширение просто ничего не делает.

Показ лимитов отключается одной кнопкой в окне расширения.

Приложение ArsWidget бесплатное и с открытым исходным кодом:
https://github.com/arsenchios/arswidget
```

**Категория**: Productivity / Workflow & Planning

**Ссылка на политику конфиденциальности**:
```
https://a.staroschuk.com/privacy/arswidget-ai-limits
```

## Обоснования разрешений

Магазин требует объяснить каждое разрешение отдельным полем. Тексты ниже
описывают ровно то, что делает код.

**`storage`**
```
Хранит выбор пользователя (включён ли показ лимитов) и последние найденные проценты, чтобы показать их после перезапуска браузера. Ничего больше не сохраняется.
```

**`alarms`**
```
Раз в минуту повторно отправляет последние известные проценты локальному приложению. Без этого значения перестают обновляться, когда приложение было выключено и запустилось позже.
```

**`notifications`**
```
Показывает два уведомления: приложение ArsWidget не отвечает, и на открытой странице лимитов не удалось найти проценты. Оба — про работоспособность самого расширения.
```

**`http://127.0.0.1:63554/*`**
```
Единственный адрес, куда расширение отправляет данные. Это локальный сервер приложения ArsWidget на компьютере пользователя. Наружу, в интернет, ничего не уходит.
```

**`https://claude.ai/*`, `https://chatgpt.com/*`, `https://chat.openai.com/*`, `https://platform.deepseek.com/*`, `https://aistudio.google.com/*`, `https://www.perplexity.ai/*`, `https://cursor.com/*`, `https://grok.com/*`**
```
Расширение читает проценты остатка лимитов со страниц Usage и настроек этих сервисов. Доступ запрошен ко всему домену, потому что это одностраничные приложения: пользователь попадает на страницу лимитов переходом внутри сайта, без перезагрузки, и точный адрес заранее неизвестен. Код проверяет адрес перед чтением и на остальных страницах не делает ничего.
```

**Обоснование удалённого кода**: расширение не загружает и не выполняет
удалённый код. Весь код в архиве.

## Раздел «Использование данных»

Отметить нужно так:

| Пункт | Ответ |
|---|---|
| Личная информация | нет |
| Информация о состоянии здоровья | нет |
| Финансовая информация | нет |
| Аутентификация | **нет** — cookies и пароли не читаются |
| Личные сообщения | **нет** — содержимое чатов не читается |
| Местоположение | нет |
| История посещений | нет |
| Действия пользователя | нет |
| Содержимое веб-сайта | **да** — только видимые числовые проценты лимитов |

Три обязательные галочки внизу:
- данные не продаются третьим лицам — **подтвердить**
- данные не используются вне заявленной цели — **подтвердить**
- данные не используются для оценки кредитоспособности — **подтвердить**

«Содержимое веб-сайта» отмечать честно нужно: формально проценты читаются со
страницы. В пояснении стоит написать, что это только числа вида «18%», они
уходят на локальный адрес и не покидают компьютер.

## Про сроки проверки

Дольше всего рассматривают расширения с широким доступом к сайтам, а их здесь
восемь. Это осознанный выбор: все нужные сервисы внесены сразу, одной подачей,
чтобы не проходить проверку по кругу ради каждого нового.

Поэтому дальше правило простое: **пока эта версия не опубликована, новые
сервисы не добавлять**. Каждый новый сайт — ещё одно разрешение, которое
проверяющий должен одобрить, и отсчёт начинается заново.

Когда версия выйдет, дешевле всего расширяться внутри уже разрешённых доменов —
там новая проверка разрешений не нужна.

GitHub Copilot намеренно не добавлен: его лимиты живут на `github.com`, а
доступ ко всему GitHub ради одного числа — это заметно более пристальная
проверка и куда более неприятное разрешение для пользователя.
