# ArsWidget AI Limits

После явного включения в popup расширение читает только видимые проценты остатка лимитов на страницах Usage/настроек Claude, ChatGPT, Codex, DeepSeek, Google AI Studio, Perplexity, Cursor и Grok и передаёт их только локально в запущенный ArsWidget через `127.0.0.1:63554`.

Оно не читает и не передаёт пароли, cookies, чаты, запросы или историю браузера. Если страницы меняют разметку, расширение не отправляет значение до обновления распознавания и через несколько минут показывает уведомление, что проценты найти не удалось.

Вместе с процентами уходит время последнего реального считывания со страницы: виджет показывает возраст значений и приглушает их, если Chrome давно ничего не присылал.

Все сайты описаны одной таблицей `SITES` в начале `content.js` — чтобы добавить сервис, нужна одна запись.

Распознавание процентов покрыто тестами: `node chrome-extension/tests/detection.test.js`. Они прогоняют `content.js` на зафиксированных раскладках страниц, поэтому смену вёрстки видно до релиза. Тесты лежат вне этой папки, чтобы не попадать в архив расширения.

Раскладки Claude, Codex, DeepSeek и Gemini сняты с настоящих страниц. Perplexity, Cursor, ChatGPT и Grok распознаются общим правилом «процент рядом со словом остатка» и на живых страницах ещё не проверялись: если сервис не появится, поправить нужно его запись в `SITES`.

Для Chrome Web Store загружается ZIP, в котором `manifest.json` лежит в корне архива.
