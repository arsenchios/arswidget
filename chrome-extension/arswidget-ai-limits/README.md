# ArsWidget AI Limits

После явного включения в popup расширение читает только видимые проценты остатка лимитов на страницах Usage/настроек Claude, ChatGPT/Codex, DeepSeek и Google AI Studio и передаёт их только локально в запущенный ArsWidget через `127.0.0.1:63554`.

Оно не читает и не передаёт пароли, cookies, чаты, запросы или историю браузера. Если страницы меняют разметку, расширение не отправляет значение до обновления распознавания и через несколько минут показывает уведомление, что проценты найти не удалось.

Вместе с процентами уходит время последнего реального считывания со страницы: виджет показывает возраст значений и приглушает их, если Chrome давно ничего не присылал.

Для Chrome Web Store загружается ZIP, в котором `manifest.json` лежит в корне архива.
