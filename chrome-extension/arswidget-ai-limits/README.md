# ArsWidget AI Limits

После явного включения в popup расширение читает только видимые проценты лимитов на страницах Usage/настроек Claude и ChatGPT/Codex и передаёт их только локально в запущенный ArsWidget через `127.0.0.1:63554`.

Оно не читает и не передаёт пароли, cookies, чаты, запросы или историю браузера. Если страницы меняют разметку, расширение не отправляет значение до обновления распознавания.

Для Chrome Web Store загружается ZIP, в котором `manifest.json` лежит в корне архива.
