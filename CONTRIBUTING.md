# Вклад в ArsWidget

Для ошибки или идеи создай Issue с коротким описанием, версией ArsWidget,
версией macOS и скриншотом при необходимости.

Перед Pull Request проверь, что проект собирается в Xcode и новая функция не
добавляет постоянную тяжёлую работу в фоне. Не добавляй ключи, токены,
пароли или личные данные в код и историю Git.
