# ArsWidget

Личный macOS-виджет вокруг Dynamic Island: музыка, календарь, напоминания,
Pomodoro с журналом задач, словарь, буфер обмена, системный мониторинг и игры.

## Установка

Готовая версия: [GitHub Releases](https://github.com/arsenchios/arswidget/releases/latest).
Скачай DMG, открой его, перенеси `ArsWidget.app` в `Applications` и запусти оттуда.
Требуется macOS 15 или новее. Выпуск 0.2.31 универсальный: Apple Silicon и Intel.
Xcode и Codex для установки не нужны. [Подробная инструкция](ИНСТРУКЦИЯ%20ПО%20УСТАНОВКЕ.txt).

Без Apple Developer macOS может один раз попросить подтвердить запуск:
`Системные настройки` -> `Конфиденциальность и безопасность` -> `Всё равно открыть`.

## Обновления

Обновления устанавливаются вручную. Кнопка в меню и в «О приложении» открывает
последний GitHub Release. Закрой ArsWidget и замени приложение в `Applications`.
Автоматическое обновление пока отключено; подписанного канала Sparkle нет.

## Возможности

- Музыка и календарь
- Напоминания Apple Reminders
- Pomodoro: задачи, комментарии и статистика
- Карточки для изучения языков и терминов
- История буфера обмена
- Системный мониторинг и режим очистки клавиатуры
- Временные режимы «Не усыплять Mac» и «Не гасить экран»: 30 минут, 1 или 2 часа
- Повторяемое знакомство с функциями: Настройки → Общие → Знакомство
- Встроенные игры
- Локальные лимиты Claude и Codex через отдельное расширение Chrome

## Приватность

Задачи Pomodoro, словарь и настройки хранятся локально на Mac. Текстовая история
буфера хранится только в оперативной памяти (до 30 записей) и исчезает при выходе.
Фотографии и файлы в неё не сохраняются. Эти данные приложение никуда не отправляет. Расширение лимитов передаёт виджету только проценты
остатка лимитов и время обновления, без паролей, cookies, переписок и запросов.

Анонимная статистика по умолчанию выключена для новых установок. Если включить
её в настройках, раз в сутки приложение отправляет отчёт: случайный идентификатор
установки (создаётся при первом запуске, не связан с аккаунтом или «железом»),
версия ArsWidget, версия macOS, язык и сколько раз открывали каждую вкладку.
Содержимое заметок, задач, словаря и буфера в отчёт не попадает. Отключается в
`Настройки` -> `Дополнительно` -> `Анонимная статистика использования`.

Форма «Предложить улучшение» отправляет только текст сообщения, версию
приложения и, если вы его укажете, способ связи для ответа.
