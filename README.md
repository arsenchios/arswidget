# ArsWidget

Личный macOS-виджет вокруг Dynamic Island: музыка, календарь, напоминания,
Pomodoro с журналом задач, словарь, буфер обмена, системный мониторинг и игры.

## Установка

Первая версия будет опубликована в [GitHub Releases](https://github.com/arsenchios/arswidget/releases).
Скачай архив, перенеси `ArsWidget.app` в папку `Applications` и открой приложение.

Без Apple Developer macOS может один раз попросить подтвердить запуск:
`Системные настройки` -> `Конфиденциальность и безопасность` -> `Всё равно открыть`.

## Обновления

ArsWidget проверяет обновления автоматически и по кнопке в меню приложения.
Когда доступна новая версия, приложение предложит скачать её и перезапуститься.

## Возможности

- Музыка и календарь
- Напоминания Apple Reminders
- Pomodoro: задачи, комментарии и статистика
- Карточки для изучения языков и терминов
- История буфера обмена
- Системный мониторинг и режим очистки клавиатуры
- Встроенные игры
- Локальные лимиты Claude и Codex через отдельное расширение Chrome

## Приватность

Данные Pomodoro, словаря, буфера обмена и настроек хранятся локально на Mac и
никуда не отправляются. Расширение лимитов передаёт виджету только проценты
остатка лимитов и время обновления, без паролей, cookies, переписок и запросов.

Раз в сутки приложение отправляет анонимный отчёт: случайный идентификатор
установки (создаётся при первом запуске, не связан с аккаунтом или «железом»),
версия ArsWidget, версия macOS, язык и сколько раз открывали каждую вкладку.
Содержимое заметок, задач, словаря и буфера в отчёт не попадает. Отключается в
`Настройки` -> `Дополнительно` -> `Анонимная статистика использования`.

Форма «Предложить улучшение» отправляет только текст сообщения, версию
приложения и, если вы его укажете, способ связи для ответа.
